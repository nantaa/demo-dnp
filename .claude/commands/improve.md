# /improve — Continuous Enhancement & Polish Command

## Purpose
Propose and implement targeted enhancements, UX polish, developer experience improvements, and operational optimizations.

## Phase
**Improve** (Part of the Improve Phase: Step 7 of the workflow)

## When to Use
- Enhancing user experience (smoother transitions, optimistic UI updates, clearer validation messages, keyboard shortcuts).
- Optimizing developer workflow (faster test runs, better seeders, streamlined local setup).
- Implementing feedback gathered from user testing and stakeholder evaluations.

## Workflow & Guidelines
1. **Identify High-Impact Opportunities**:
   - Focus on changes that demonstrably improve usability, reliability, or developer velocity.
   - Guard against feature creep — adhere to YAGNI and ensure improvements directly serve current user needs.
2. **Design & Validate**:
   - Write failing or baseline tests for any behavioral enhancements.
   - For UI improvements, ensure visual harmony and maintain responsive design standards.
3. **Execute & Test**:
   - Implement the enhancement cleanly.
   - Verify that existing workflows and stage gates remain intact.
4. **Document**:
   - Summarize the enhancements and their rationale in commit messages and documentation.
