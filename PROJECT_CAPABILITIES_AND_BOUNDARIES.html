✕ EXPLICIT LIMITATION OUT OF SCOPE

Experimental "v3" 20-Stage Branch is Excluded

Why v3 is NOT in this project: The experimental v3 branch was an over-engineered proof-of-concept that fragmented the pipeline into 20 stages, introduced broken circular dependencies with @domain/workflowEngine, and caused widespread confusion among field teams. Production is strictly locked to the stable 16-stage pipeline on branch main.

v3 Excluded No 20 Stages No @domain/workflowEngine
✕ EXPLICIT LIMITATION OUT OF SCOPE

No Government Ministry (Disnaker/Kemnaker) API Integration

Government offices (Disnaker & Kemnaker) do not provide public authenticated REST APIs for inspection dockets. All Stage 8 (Proses Disnaker) tracking relies on internal SLA timers and manual input of official government receipt numbers (Tanda Terima Disnaker).

No Disnaker API No Kemnaker API Manual Receipt Logging
✕ EXPLICIT LIMITATION OUT OF SCOPE

No Automated Bank Reconciliation / Payment Gateway

There is no direct integration with BCA/Mandiri Open Banking APIs or payment gateways (Midtrans/Xendit). Payment clearance in Stage 14 requires human verification of uploaded Bukti Transfer receipts. The system does not auto-scrape bank account mutations.

No Bank Mutation Scraping No Payment Gateway Manual Bukti Transfer Check
✕ EXPLICIT LIMITATION ARCHITECTURE BOUNDARY

No Real-Time WebSockets (Pusher / Soketi)

The system intentionally does not operate a WebSocket server (such as Laravel WebSockets, Soketi, or Pusher) to maintain zero external background daemon overhead. Instead, it uses defensive 8-second HTTP polling on the Kanban board and notification hub.

No WebSockets No Pusher Dependency Lightweight 8s Polling
✕ EXPLICIT LIMITATION INFRASTRUCTURE BOUNDARY

No Multi-Tenant SaaS Architecture

The platform is architected as a dedicated, single-organization enterprise application. It does not provide tenant-isolated database partitioning, custom subdomains per company, or billing subscription meters. All users belong to the internal inspection organization.

Single Enterprise Only No Multi-Tenant Dedicated DB
✕ EXPLICIT LIMITATION CLIENT PLATFORM

No Native Mobile App (PWA / Mobile Web Only)

There are no native iOS (Swift) or Android (Kotlin) app packages or offline SQLite synchronization engines. The application operates as a fully responsive Inertia + React web application accessible through Chrome/Safari mobile browsers with camera photo upload capabilities.

No Native App No Offline Cache Sync Responsive Web App

Academic Thesis Docket Resides in a Separate Repository

The 7-stage educational dissertation workflow is completely decoupled from this codebase. It maintains its own independent repository at github.com/nantaa/thesis-docket to prevent domain pollution between industrial machinery inspection and student academic defense.
